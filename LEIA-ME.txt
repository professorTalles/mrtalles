SPHERE WORLD — BUILD 6×6

Envie todo o conteúdo desta pasta para a raiz do repositório GitHub Pages.
O Code the Bee usa uma grade 6×6, mantendo o percurso de oito movimentos.
A abelha mantém largura e altura iguais, com tamanho mínimo responsivo de 40px.
O crédito permanece no rodapé, em posição mais alta e legível.

Trilhas locais: assets/music/menu.mp3, shapes.mp3 e bee.mp3.
Se o navegador móvel bloquear autoplay, toque uma vez na tela para iniciar.
Se a versão antiga continuar aparecendo, limpe os dados/cache do site ou remova o PWA antigo.
