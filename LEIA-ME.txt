SPHERE WORLD — PACOTE VERTICAL OFFLINE / GITHUB PAGES

1. GitHub Pages: envie todo o conteúdo desta pasta para a raiz do repositório.
2. Celular: abra o endereço HTTPS publicado e, se necessário, limpe o cache/PWA antigo antes de instalar novamente.
3. Computador offline: sirva esta pasta por um servidor local. No Windows, execute `py -m http.server 8000` dentro dela se o Python estiver disponível; em macOS, execute `python3 -m http.server 8000`.

A versão inclui o menu vertical, logo ampliada, rodapé flutuante, SETTINGS em todas as telas, volumes separados de música/efeitos/voz, três MP3 locais e grade 6×6 no Code the Bee.
